# Salary Prediction

A compact Streamlit dashboard and ML project to predict salaries from job-related features. Explore the data, compare models, and make interactive salary predictions in a few clicks.

Live demo: https://ai-job-insight.streamlit.app/Salary_Prediction

## Key features (Streamlit dashboard)
- Interactive prediction form — enter job features and get a salary estimate instantly.
- Exploratory Data Analysis — view distributions and correlations for key features.
- Model comparison & metrics — compare performance (RMSE, R²) across available models.
- Feature importance — see which inputs influence predictions the most.
- Easy-to-use UI with sidebar controls to switch models and set parameters.
